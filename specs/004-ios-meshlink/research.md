# Research: iOS NTsocial MeshLink Companion

## Findings

1. Kable 0.42 is the correct single Apple BLE owner. The implemented iOS layer uses Kable/CoreBluetooth availability, reconstructs peripherals by UUID, configures central state restoration, and uses the negotiated maximum write length. Adding a second Swift BLE actor would create competing ownership and reconnect state machines.
2. The repository now includes root iOS smoke coverage, Room KSP for iosArm64/iosSimulatorArm64, a static `MeshLinkKit` framework, and a SwiftUI/Xcode host. Focused device/simulator compilation and simulator framework linking pass. This is still distinct from executing Kotlin/Native tests: the build convention currently disables native test link/run tasks.
3. The former active-path iOS blockers were replaced: random bytes use `SecRandomCopyBytes`, preferences use file-backed DataStore paths, Room uses an iOS SQLite builder, and Bluetooth uses the real Kable implementation. These source facts do not prove behavior on a physical radio.
4. The iOS runtime is a real Koin composition root over the existing shared radio controller, repositories, Room model, `MeshServiceOrchestrator`, and a Room-backed durable message queue. Cold start first hydrates the persisted selected address, switches its per-radio database, loads the active database's node cache from a direct authoritative snapshot, and only then connects. Startup/reconnect replay treats Room `QUEUED` rows as work records and does not claim RF delivery.
5. Android's ContentProvider/broadcast/UID IPC cannot be transplanted to Apple. The implemented Apple Gateway uses an explicitly versioned App Group SQLite mailbox, a shared-Keychain HMAC key, payload-free Darwin hints, and a deep link. Authoritative routes and restart-stable idempotency remain private to MeshLink.
6. The implemented route registry uses 32 CSPRNG bytes encoded Base64URL, 120-second expiry, exact caller/source/captured-slot/generation binding, and generation rotation on process start or channel/routing-context inequality. The parent never chooses a raw radio slot.
7. The App Group data plane separates bounded complete-`NM` overlay ingress from stable-only native broadcast-text changes. Native rows are exported only when stable source identities were captured at private-Room insertion; nullable legacy identities are not reconstructed from current slots. Additive schema-v1 `overlay_epoch_state` stores per-epoch allocation high-water independently of the 128 retained rows, is transactionally backfilled for an early v1 database, and prevents sequence reuse after eviction without changing `user_version`.
8. The separately authorized `NTsocial_release` source now includes the Swift Gateway adapter, shared HMAC codec, exact v1 Keychain service/account coordinates, SQLite mailbox access, Darwin/deep-link handoff, production payload provider, canonical-store import, authenticated native broadcast-text enqueue, and restart-stable parent correlation. A first-send pending admission durably records exact message/attempt/transport `.queued` plus `.admission`; multipart correlation retains final social-header ID, attempt, part kind/index/count, transfer ID, and logical channel. Outbound retains duplicate source slots while canonical/history projection collapses equal stable identities by PRIMARY then lowest slot and rejects security conflicts. A gap, malformed envelope, or lost/expired transfer is bypassed only after a durable gap/quarantine/abandoned terminal record; transient failure keeps the cursor fixed and evicted rows are not claimed recoverable. The focused adapter suite passes 27/27, the full SwiftPM suite passes 668/668, and the release build is green. The parent composer remains intentionally deferred. This is implementation evidence, not signed two-app interoperability proof.
9. Source declarations align on bundle IDs, App Group, Keychain suffix, deep link, and Darwin names. Apple Developer identifiers/profiles and signed physical-device access remain unverified; matching plist/entitlement text alone cannot prove sandbox access.
10. The focused companion UI should remain small: integration/Bluetooth/background readiness plus scan/select/connect/disconnect/forget. Routes browsing, native-text diagnostics, command-result administration, Gateway reset/panic wipe, maps, and broad settings would duplicate parent or nonessential tooling and are deferred.
11. iOS has no Android foreground-service equivalent. CoreBluetooth restoration and Darwin notifications improve recovery only while Apple permits execution; neither proves permanent background service or terminated-app command wake.
12. The simulator host builds with a source Privacy Manifest and AppIcon asset catalog, installs, cold-launches, remains alive, and renders. An earlier source revision retained a clean signing-disabled Simulator Debug zero-byte quiet log, compiled AppIcon/root `PrivacyInfo.xcprivacy`, and a signing-disabled generic-iphoneos Release arm64 Mach-O App with successful plist/privacy lint and no Xcode/linker/ICU warning. Current-source clean-build numbers remain pending; all such artifacts are unsigned source-build evidence.
13. The former Skiko ICU 18.5-versus-17.0 linker warning is closed without raising the deployment target. The build phase accepts only the verified member with zero `__text`, one ICU data symbol, and unchanged `__const` bytes; it relinks that data-only member's LC_BUILD_VERSION to iOS 17, atomically rebuilds the archive, and fails closed on an unexpected layout. A signed archive still needs the same verification.
14. Route/inbound identity now includes an atomic monotonic session epoch, selected/active radio equality, exact-epoch configuration completion, selected radio's active Room database, complete-channel readback/final-snapshot generations, history epoch, Bluetooth permission/power, transport/App connection state, and complete channel fingerprint. Route issue and admission recheck the same guard under `ChannelOperationLock`; every routing-context inequality rotates the opaque generation and revokes old capabilities.
15. A `READY` transition drains the durable mailbox. Retryable work is coalesced into one bounded 500/1,000/2,000-ms job with at most three attempts; exhaustion of the 64-command per-pass budget schedules a delayed continuation so the next item is neither starved nor processed in a busy loop.
16. An authenticated exact accepted-ledger record is consulted before process-local route resolution, allowing restart recovery after accepted-ledger commit but before result publication without a second local admission. Different content conflicts. The earlier local-admission/ledger-commit crash gap remains a possible physical RF duplicate, so this is not exactly-once radio delivery.
17. Radio replacement uses a transport-generation callback facade with synchronized validation and side effects, so an already retired transport cannot reconnect, disconnect, deliver bytes, or dispatch an exact-session raw send into the replacement session—even for the same address or reused transport object. It pauses and awaits admitted ingress/child work and the retired outbound queue/status/log generation before switching databases; already-dequeued old packets and late persistence cannot cross the boundary.
18. Manual/QR apply, public protected-channel reconcile, and built-in provisioning share one serialized mutation contract: validate/ensure → invalidate Gateway ingress → exact-session firmware mutation → correlated fresh readback → activate the verified final identity. A short operation lock is not retained while the Stage 1 producer commits. Rejection, mismatch, timeout, or replacement remains closed rather than trusting cache state.
19. Current-source focused executable evidence is 135/135: domain 16/16, data 104/104, and iOS runtime 15/15. Runtime distribution is session/active-database guard 4, bounded retry 3, command-drain budget 3, durable-dispatch identity 2, inbound-projection signal 1, and shell/deep-link 2. Gateway JVM tests separately pass 36. These host-side JVM results complement, but do not replace, the currently disabled Kotlin/Native iOS test execution gate.
20. A durable Gateway row retains the source identity accepted with its route. Actual iOS drain revalidates the exact active session/ingress and slot-derived PSK/LoRa source identity, then holds the operation boundary through exact-session queue admission and matching firmware QueueStatus. Channel replacement before drain fails closed instead of sending through a reused numeric slot.
21. Exact fresh readback reuses firmware's `69420` config-only sentinel; it does not invent a firmware nonce. A host-exclusive owner/token may start only after the prior FULL Stage 2 has completed and no other owner exists. Its dedicated completion flow rejects stale/parallel FULL responses, old sessions, and generic generation movement, and config-only completion does not start FULL Stage 2/readiness side effects.
22. Deterministic same-address, admin/readback/raw-send, accepted-before-drain replacement, mutation/readback producer, stale/parallel handshake, and premature-activation tests plus the final bounded audit found no reproducible P0/P1 in these boundaries.
23. The one known open source P2 is bounded liveness when an admitted exact readback times out/cancels and firmware never returns a late response. That same epoch remains fail closed until reconnect/new epoch. This is not wrong-channel dispatch, cross-session mutation, or data disclosure.

## Chosen scope

Ship the smallest architecture that creates real LoRa value for the NTsocial parent:

- MeshLink exclusively owns one Meshtastic BLE session;
- the parent sends authenticated durable complete `NM` commands through Apple Gateway;
- MeshLink exposes bounded overlay ingress and stable-only native broadcast text;
- the parent owns social UX and canonical history;
- the companion UI exposes only connection and integration health/actions;
- all acceptance wording separates local durable admission from RF and remote delivery.

Defer non-BLE transports, broad Meshtastic UI parity, and release claims until signed App Group/Keychain, physical BLE/radio/RF, lifecycle, native-test, signed-archive toolchain, and App Store gates are closed.
